# 🐱 گربه دونده | Cat Runner — نسخه ۲.۰

یک بازی ساده و فان برای مرورگر؛ گربه می‌دود، می‌پرد و از موانع رد می‌شود.
ساخته‌شده با HTML، CSS و JavaScript بدون هیچ کتابخانه خارجی.

## ویژگی‌ها
- پرش و پرش دوتایی، خم شدن (Duck)، پرش کوتاه/بلند با رها کردن کلید
- موانع: کاکتوس (تکی و دوتایی)، سنگ، پرنده (بالا و پایین)
- سکه، پاورآپ سپر 🛡️ و آهنربا 🧲
- سرعت تدریجی، سه درجه سختی، چرخهٔ شب و روز
- فروشگاه با ۷ شخصیت، ذخیرهٔ سکه، رکورد و ۵ امتیاز برتر در مرورگر
- توقف (P)، قطع صدا (M)، افکت صوتی و موسیقی (background.mp3)
- ریسپانسیو با دکمه‌های لمسی برای موبایل

### جدید در نسخه ۲.۰
- **سه قدرت جدید:** ✨ امتیاز دوبرابر (۱۰ ثانیه)، 🚀 سرعت‌دهنده (۵ ثانیه، شکست‌ناپذیر و خردکنندهٔ موانع، با خطوط سرعت و رد گربه)، 💖 نجات یک‌باره
- **مأموریت‌ها (۱۲ عدد) و دستاوردها (۹ عدد):** جایزهٔ سکه فقط یک بار قابل دریافت است
- **رابط:** منوی اصلی، توقف و پایان بازی بازطراحی‌شده، نوار قدرت‌های فعال با نوار زمان، انیمیشن‌های ملایم (با احترام به «کاهش حرکت» سیستم)
- **موبایل:** دکمه‌های لمسی بزرگ، حالت افقی تمام‌صفحه، safe-area، ارتعاش، نمایش واضح روی صفحه‌های نمایش پرتراکم
- **صدا:** موسیقی و افکت‌ها جدا از هم (روشن/خاموش و بلندی)
- **ذخیره:** خروجی JSON و بازیابی با اعتبارسنجی (ساختار، نسخه، مقادیر، چک‌سام)؛ ذخیرهٔ نسخهٔ ۱ به‌صورت خودکار منتقل می‌شود و یک پشتیبان `catRunnerSave_v1_backup` هم نگه داشته می‌شود

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار روی GitHub Pages
1. فایل‌های `index.html`، `style.css`، `game.js`، `README.md` (و `logo.png` / `background.mp3` در صورت وجود) را در ریشهٔ مخزن جایگزین کنید.
2. `git add . && git commit -m "v2.0" && git push`
3. در GitHub: Settings → Pages → Branch: `main` / root. چند دقیقه بعد آدرس `https://<username>.github.io/my-game/` به‌روز می‌شود.
4. اگر نسخهٔ قدیمی دیده شد، یک بار Hard Refresh (Ctrl+Shift+R) بزنید.

ذخیرهٔ بازی در مرورگر و به‌ازای هر دامنه است؛ برای انتقال بین دستگاه‌ها از «خروجی JSON» و «بازیابی از فایل» در تنظیمات استفاده کنید.
